# Bounded routing and execution

Routing is deterministic: A01 always investigates; A02 is selected for retrieved correction/supersession/conflict or configured prerequisites requiring reconciliation; A03 for a nonempty retrieved inventory; A04 for an authorized linked decision. Skipped specialists are persisted as not_selected. This avoids a routing model call whose benefit has not been demonstrated.

Global ceiling: seven logical model invocations, A01 at most four and each specialist one. Multi-agent retries are disabled. At most five actual/cached tool requests execute in A01. Excess requested calls are explicitly denied with tool_budget_not_executed, recorded separately, and the preserved graph makes its bounded final-draft request. The legacy single-agent budget behavior is unchanged.

Multi-agent output ceiling defaults to 4,000 tokens per invocation, configurable through MULTI_AGENT_MAX_OUTPUT_TOKENS from 256 to 6,000. This is separate from the legacy OPENAI_MAX_OUTPUT_TOKENS. MULTI_AGENT_REASONING_EFFORT defaults to low (minimal/low/medium/high permitted) and is recorded; optional OPENAI_REASONING_EFFORT leaves legacy behavior unchanged when unset. The effective ceiling and requested model are recorded in each run; no automatic model switching occurs. No per-agent model routing is enabled. Calls use the currently configured provider/model. Input context is bounded by characters, not an exact tokenizer count. Provider usage/reported model/response ID/error and latency are persisted. Currency cost estimation remains unavailable.

Workflow checks its 180-second deadline before each specialist; an already-running call retains the provider timeout (default 30 seconds). This is not a process-level hard wall-clock cancellation guarantee. A01 retains its deadline and step/tool limits. Failure/timeout/invalid output leaves validated partial agent results available but marks the unified packet partial and abstained. Required agent failure blocks summary approval. Interrupted runs remain interrupted and cannot publish a complete packet; stale workers are handled by existing fetch timeout logic.

Freshness is checked after retrieval and all specialists, and again at submission/review. Source or decision-policy change prevents reuse. Duplicate requests replay the existing run without model calls; changed question, mode or bound snapshot returns an idempotency conflict. No automatic single-agent fallback occurs: it remains a separate explicit user choice.
