# Trace-level root causes

The verified historical complete case spent two A01 calls (6,278 input tokens), then 4,069 input on A03 and 4,102 on A04 even though configured prerequisites were present. The conflicting case spent four A01 calls (12,403 input) and then three sequential specialist calls (13,100 input). Specialist wall durations were 5,946, 9,148 and 6,737 ms. Missing-prerequisite used three A01 calls (9,600 input), A03 (3,325) and A04 (3,358); document search returned empty twice under different arguments.

A03 was routed for any evidence, rather than an actual longitudinal objective. A04 was routed for any decision, rather than a missing/unavailable prerequisite. All specialists received the same evidence, obligation and stage context. The projection retained complete normalized metadata and repeated values inside support templates; conversation history repeated source payloads after observation/provenance/quality reads. The cache reused exact requests only; provenance and quality call the same underlying source read but could not share entries. Source strings were prefix-truncated at fixed character boundaries. Persistence performed two run reads and two JSON updates for every checkpoint.

Model calls dominate the measured runs: actual tool latency totals were only 316 ms (complete), 135 ms (conflicting) and 205 ms (missing prerequisite). These sums cannot establish exact model latency because historical provider timing/context-size fields are missing. New instrumentation records provider invocation time, input/schema/tool-definition characters, each tool's response size, references, cache status, retries, errors and grounding per run/agent. Original trace gaps remain null/unavailable rather than fabricated.

Independent specialists depend on sealed sources rather than one another. Their model calls may overlap after authorization and call-budget reservation; deterministic validation/merge and all persistence remain serial. Primary cases may benefit chiefly from skipping agents, so a separate serial-versus-parallel case is needed before attributing latency gains to concurrency.

The CSV distinguishes final agent supporting references from input references. input_refs_recorded=false means the older instrumentation did not capture input IDs; it does not mean no evidence was sent. Actual tool evidence IDs remain available. The additional full_m08_ui rows come from the retained optimized app run and include its newer per-invocation input references. Unavailable historical timing/size fields are blank. Tool-purpose and cache columns distinguish model-selected reads, deterministic lineage reads and reused results.
