# Ajyra AI - ReproBridge v0.2 defect register

The audit recorded nine defect groups. Each has a regression check or a repeatable verification procedure.

| ID and severity | Component and reproduction | Root cause | Remediation and verification |
| --- | --- | --- | --- |
| RB-01 Critical | Review a missing-evidence proposal after adding a valid record, then close. Baseline returned HTTP 200 twice. | A review captured the latest evidence at decision time without checking the evidence or purpose of the generated proposal. | Approvals reject stale proposals. Closure requires an approved evidence-verification proposal whose evidence still matches. API regressions and both browser journeys exercise the separate approval gates. Fixed. |
| RB-02 Critical | Close an obligation and import a contradictory or invalidating record of the same kind. Baseline still showed closed. | The write path had no impact check for a completed obligation or its dependents. | Affected obligations and closed dependents reopen atomically. Earlier closure links and audit entries remain available. Tests cover an invalidation marker, a late trigger conflict, dependent reopening, a fresh review, and current FHIR Task output. Fixed. |
| RB-03 High | Change the trigger or closure requirements for an already persisted version, then evaluate. | Evaluation used deployed definitions while review and closure used the stored version. | Compare the existing definition before evaluating the same version and fail closed on drift. The drift regression checks both evaluation and transition rollback. Fixed. |
| RB-04 High | Close a prerequisite before registration, or introduce a malformed dependency out of band before closure. | Only open predecessors were linked. The edge lacked an explicit type and closure trusted stored topology. | Create typed links to the applicable predecessor in either status. Validate configuration, patient, and direction on creation. Recheck required edges at closure. The suite exercises duplicate and missing foreign keys, cyclic corruption, provenance, and dependent reopening. Fixed. |
| RB-05 High | Inject a graph failure or interrupt before routing, then retry. | The transaction rolled back without any agent failure record. | Record failed execution and audit without producing an actionable task. Return a retryable HTTP 503. The same pending run is reused for unchanged evidence. Error and interruption tests verify recovery and tracing. Fixed. |
| RB-06 Medium | Inspect initial timeline after import, or race registration requests. | The initial milestone was display-only. Persistence relied on service checks for uniqueness. | Persist the initial event, backfill from import audit, and add database uniqueness for patient and stage and patient and rule. Tests cover concurrent registration, invalid stages, and migration. Fixed. |
| RB-07 Medium | Import an Observation with an unresolved Encounter reference and export the bundle. | Structural validation alone checked neither the patient-local graph nor intended reference types. The response used generic JSON. | Validate patient-local references and selected targets, export a consistent read snapshot with FHIR media type, and validate the serialized collection. API checks and downloaded-bundle validation cover the contract. Fixed. |
| RB-08 Medium | Configure two demo roles with the same bearer token and request a session. | The first configured matching role won. | Reject ambiguous credentials. Regression verifies duplicate, missing, and invalid credentials. Backend role regression continues to verify distinct mutating permissions. Fixed. |
| RB-09 Medium | Serve the application against a database at an older revision and use readiness to admit traffic. The original browser harness also exercised SQLite only. | Readiness accepted any recorded revision. The browser runner had no PostgreSQL isolation option. | Readiness checks the expected schema. The migration test verifies readiness on both sides of the upgrade. The browser runner provisions a fresh PostgreSQL schema for each journey and replay. Fixed. |
